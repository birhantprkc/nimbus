## Examples

### Sizing

Use `size` for equal width and height, or `width`/`height` individually. Tailwind utility classes on the element also work.

<Example
  code={`<Icon name="ph:star" size={16} />
<Icon name="ph:star" size={24} />
<Icon name="ph:star" size={32} />`}
  minHeight="6rem"
>
  <div class="flex flex-wrap items-center justify-center gap-6">
    <Icon name="ph:star" size={16} class="text-foreground" />
    <Icon name="ph:star" size={24} class="text-foreground" />
    <Icon name="ph:star" size={32} class="text-foreground" />
  </div>
</Example>

### Accessibility

Pass `title` and `desc` to add `<title>` and `<desc>` elements inside the SVG for screen readers.

<Example
  code={`<Icon name="ph:warning" title="Warning" desc="This action cannot be undone" class="w-6 h-6" />`}
  minHeight="6rem"
>
  <div class="flex items-center justify-center">
    <Icon
      name="ph:warning"
      title="Warning"
      desc="This action cannot be undone"
      class="w-6 h-6 text-foreground"
    />
  </div>
</Example>

### Inline mode

By default, `Icon` renders a `<symbol>` + `<use>` pair so the same icon can be referenced multiple times without duplicating the SVG body. Set `is:inline` to inline the raw SVG paths when you need them in the DOM.

<Example
  code={`<Icon name="ph:check-circle" is:inline class="w-6 h-6 text-green-500" />`}
  minHeight="6rem"
>
  <div class="flex items-center justify-center">
    <Icon name="ph:check-circle" is:inline class="w-6 h-6 text-foreground" />
  </div>
</Example>

### With Tailwind classes

Any class on the `<svg>` element works — color, size, transitions, etc.

<Example
  code={`<Icon name="ph:heart" class="w-8 h-8 text-red-500 hover:scale-110 transition-transform" />`}
  minHeight="6rem"
>
  <div class="flex items-center justify-center">
    <Icon
      name="ph:heart"
      class="w-8 h-8 text-red-500 hover:scale-110 transition-transform"
    />
  </div>
</Example>
